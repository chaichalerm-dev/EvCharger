# UI Flow

Dashboard establishes context. Map layers/search/radius lead to site analysis. Site detail separates overview, recommendation, and business simulation. Comparison uses one configuration version. Partners and branches support host conversations. Lifecycle actions explain consequences.

Desktop uses persistent navigation and a three-column GIS workspace. The sidebar can collapse to an icon rail and remembers that device-local preference. Tablet uses a compact navigation rail and overlays site intelligence. Mobile uses one accessible menu button that changes to a close icon while the drawer is open; it never displays a separate duplicate close control.

The first visit starts in Thai and light mode. Users can switch between Thai/English and light/dark/system from the header or Settings. The document language follows the selected interface language, and bundled Noto Sans Thai/Noto Sans fonts provide readable scripts without a network font dependency.
