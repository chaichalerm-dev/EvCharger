# Product Flow

Start screen → Find a location → Set radius/site area → Analyze this area → Review score, recommendation, reasons, risks and missing information → Compare → Opportunity review → Confirmed business decision.

The start screen presents one primary action and previews the outputs before showing portfolio detail. The map keeps the same three-step journey visible and identifies the next required action. Advanced layers and API configuration remain secondary so a first-time user can complete a public location analysis without understanding the architecture.

Partner path: Submit → Validate → Local prototype persistence → Analyze → Score → Recommendation → Review. Production adds authenticated ownership, evidence upload, backend validation, audit, and notifications.
