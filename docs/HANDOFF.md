# Handoff

## Demonstration script

1. Open Dashboard and explain the expansion portfolio.
2. Open Map, search Bang Na, change radius/layers, and select the opportunity.
3. Open Full Analysis. Show verified versus estimated data, score factors, recommendation reasons, risks, gaps, and simulation disclaimer.
4. Add sites to Compare.
5. Show partner submission and the local-storage warning.
6. Show branch ranking, lifecycle confirmation, Demo Role, and failure simulation.

## Owner checklist

- Confirm business assumptions with commercial, electrical, GIS, flood, finance, legal, and operations owners.
- Replace fixtures only through repositories/providers.
- Select backend/auth/provider strategy.
- Establish data licensing and PDPA controls.
- Implement audit, observability, backup, and incident response before production.

The current product is a demonstrable prototype, not a final investment system.
