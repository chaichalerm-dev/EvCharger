# Contributing

Read README.md and AI.md. Create a focused branch, inspect existing boundaries, update code and tests, run all validation, update docs/ADR when behavior or architecture changes, and open a review with screenshots only when useful.

Do not commit .env files, secrets, personal submissions, build output, or copied production data. Do not change weights, thresholds, permissions, financial assumptions, or quality semantics without an explicit business decision and tests.
